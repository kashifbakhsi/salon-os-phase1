# SalonOS — Phase 1 Starter

A full-stack salon booking and management platform starter.

## Phase 1 scope
- Customer, Staff, Salon Admin, and Super Admin roles
- Multi-salon architecture
- Customer booking flow
- Salon management
- Services and staff
- Availability
- Appointments
- Payments
- Future-ready notifications, reviews, memberships, queue, and analytics

## Planned stack
- Frontend: Next.js + TypeScript + Tailwind CSS
- Backend: NestJS + TypeScript
- ORM: Prisma
- Database: PostgreSQL
- Auth: JWT + bcrypt
- Payments: Razorpay
- Notifications: WhatsApp Business API + email

## Repository structure

```text
salon-os/
├── frontend/
├── backend/
├── docs/
└── README.md
```

## Phase 1 principle

This starter intentionally contains architecture and planning documents rather than a complete production implementation. Phase 2 will add the actual Prisma schema, database migrations, NestJS modules, authentication, and frontend screens.
